1. สำรวจพหุนามดีกรีสาม

พิจารณาพหุนามที่สร้างจากตัวประกอบสามวงเล็บ

P(x) = (x − a)(x − b)(x − c)

เลื่อนตัวปรับค่า a, b และ c แล้วสังเกตว่าพหุนามและกราฟเปลี่ยนไปอย่างไร

(x + 2)(x − 1)(x − 3)
P(x) = x³ − 2x² − 5x + 6
รากของพหุนาม: x = −2, 1, 3

แนวคิดสำคัญ: เมื่อแทน x ด้วย a, b หรือ c จะทำให้ตัวประกอบวงเล็บหนึ่งเป็นศูนย์ ดังนั้น P(x) = 0

2. กราฟเปลี่ยนแปลงแบบเรียลไทม์

กราฟด้านล่างจะปรับตามค่าที่เลื่อน จุดสีส้มแสดงตำแหน่งที่กราฟตัดแกน x

เส้นกราฟ: P(x) จุดสีส้ม: รากของสมการ

ลองตั้งค่า a, b หรือ c ให้เท่ากัน แล้วสังเกตการสัมผัสหรือการตัดแกน x ของกราฟ

3. เรียนรู้วิธีแยกตัวประกอบด้วยการจัดกลุ่ม

ตัวอย่าง: แยกตัวประกอบ x³ + 2x² + 3x + 6

ขั้นที่ 1 จัดกลุ่มพจน์
(x³ + 2x²) + (3x + 6)
ขั้นที่ 2 ดึงตัวประกอบร่วมของแต่ละกลุ่ม
x²(x + 2) + 3(x + 2)
ขั้นที่ 3 ดึง (x + 2) เป็นตัวประกอบร่วม
(x + 2)(x² + 3)
x³ + 2x² + 3x + 6 = (x + 2)(x² + 3)

สังเกตว่าแต่ละกลุ่มมีตัวประกอบร่วมเป็น (x + 2) จึงสามารถดึงออกมาเป็นตัวประกอบร่วมได้

4. ทดลองเลือกวิธีให้เหมาะกับโจทย์

โจทย์: x³ − 4x

เลือกวิธีที่เหมาะสมก่อนดูเฉลย

5. คำถามท้ายกิจกรรม (3 ข้อ)

เลือกคำตอบให้ครบ แล้วกดตรวจคำตอบเพื่อดูคะแนนและเฉลย

ข้อ 1. ข้อใดเป็นการแยกตัวประกอบของ x³ + 3x² + 2x



ข้อ 2. การแยกตัวประกอบ x³ − 9x ควรเริ่มจากวิธีใด



ข้อ 3. ข้อใดคือผลการแยกตัวประกอบของ x³ + 2x² + 3x + 6 ด้วยการจัดกลุ่ม



เฉลยพร้อมวิธีคิด
1) ก. x(x + 1)(x + 2) เพราะดึง x ออกก่อน จะได้ x(x² + 3x + 2) และ x² + 3x + 2 = (x + 1)(x + 2)
2) ก. ดึง x เป็นตัวประกอบร่วม: x³ − 9x = x(x² − 9) = x(x − 3)(x + 3)
3) ก. จัดกลุ่ม: x²(x + 2) + 3(x + 2) = (x + 2)(x² + 3)
